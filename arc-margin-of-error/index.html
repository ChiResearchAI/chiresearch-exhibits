Cost burden, with its margin of error

A working example built on the Atlanta Regional Commission's own published data · ChiResearch Technologies, LLC · 6 November 2026

What this is. A working demonstration, not deployed production software and not an ARC product. It runs on ARC's own public ArcGIS Online service — org opendata@arc, service ACS 2023 Housing Affordability, FeatureServer layers 11 (County), 9 (City) and 21 (Tract), retrieved 6 November 2026. Every figure below is computed from fields ARC publishes; nothing is modelled, imputed or simulated. The analysis is reproducible from the source service with the two scripts linked at the foot of this page.

Exhibit A asks that the Regional Housing Dashboard let users “compare housing conditions across counties and municipalities” and “sort, filter, and compare jurisdictions.” ARC already publishes, beside every estimate, the Census margin of error for that estimate. This exhibit tests one claim our approach rests on: that a comparison built on the estimate alone is not safe below county level, and that the margin of error therefore has to be first-class data in the application rather than metadata behind a click.

“No reliable estimate” is a state the interface has to render, not a blank cell.

One measure reported and then set aside. At every level — county baseline included — 100% of adjacent pairs in the sorted list are statistically indistinguishable. That result is forced by construction and is not a finding: adjacent ranks differ by a fraction of a point by definition while the margins are several points wide, so the comparison can only fail. It is named here because the informative version of the same question is rank distance to significance, which is a measured property of the data rather than an artifact of sorting. Only the coefficient-of-variation bands, the median CV and the rank-distance figures should be read as findings.

The application

Pick a geography and an indicator. The map, the scatterplot, the distribution and the table are one selection: hover or click anywhere and the same geography highlights everywhere. Turn on Flag unreliable estimates to see what the comparison looks like once the margin of error is allowed to speak.

What this means for the build

  • Margin of error travels with the estimate everywhere. It is a column in the indicator model, not a metadata panel — because the comparison feature Exhibit A asks for is the feature most exposed to it.
  • Reliability is a rendered state with three bands and a glyph, so the signal survives colour-vision deficiency, greyscale printing and forced-colours mode. Red and green at these steps are 4.1 ΔE apart under deuteranopia, which is why the band is always written as well as shaded.
  • Sorting on an unreliable estimate is a design decision, not a default. A ranked municipal table is offered with the reliability column beside it and the option to exclude estimates that cannot support a rank.
  • “No reliable estimate” is a first-class value. 155 of the geographies ARC publishes across these three levels carry no usable estimate and margin-of-error pair; the interface says so rather than showing an empty cell.
  • Vintages overlap in the live catalogue. ARC's own org currently publishes 33 services for 2020, 32 for 2021, 26 for 2022 and 7 for 2023 — the partially-rolled-out condition that makes “add a new vintage, retire the old one” (Q&A 147, 170) a first-order administrative workflow rather than a convenience.

What this exhibit cannot tell you

  • It covers one indicator family — housing cost burden — from one vintage, ACS 2023 five-year. Other indicators in ARC's catalogue will have different reliability profiles.
  • It uses ARC's published percentages and margins as given. It does not re-derive them from Census microdata, and it does not audit ARC's own aggregation.
  • The coefficient-of-variation bands (15% / 30%) are the Census Bureau's conventional thresholds. They are a convention, not a law; a different threshold moves the counts.
  • Rank distance to significance is computed pairwise on the published margins using the Bureau's own approximation for comparing two estimates. It assumes independence between geographies, which is an approximation at tract level.
  • Geometry is simplified for display only. Every statistic is computed from attributes, never from geometry.
  • It demonstrates a method and an interface. It is not evidence that ChiResearch has delivered a production system of this kind for a public agency.
